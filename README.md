# IssueHub Mini

En minimal frontend (HTML/CSS/JS) för att öva **GitHub Flow** med:
- GitHub Issues
- Branch per issue
- Pull Requests
- Code Reviews
- Merge till main

## Start
Öppna `index.html` i webbläsaren.

## WorkFlow
- 1. Create an issue with description, label and assignee
- 2. Create a branch from "main" connected with the issue
- 3. Implement the issue fix in the code
- 4. Do one or more commits
- 5. Create a Pull-Request against "main"
- 6. Add a reviewer and labels
- 7. Get feedback from assignes and update code
- 8. Merge Pull-Request to "main"
